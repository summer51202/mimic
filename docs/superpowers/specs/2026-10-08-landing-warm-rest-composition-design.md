## 2. 核心情緒與觀看順序

使用者選定「抵達一個有人陪伴的暖火休息處」：訪客剛走進來，伙伴已在火邊自在休息，前側仍有可以加入的空間。作戰會議室是房間背景，不是正式簡報或等待指令的場面。

觀看順序：暖火與伙伴這個共同焦點；開始冒險木牌；法師與地圖的小動作；房間及外圍發現。Mimiku 是共同焦點內的陪伴辨識點，不是獨立的巨型角色展示。

已選擇「開口式火邊群組」，而非小隊集中於單側的休息角落，以保留完整伙伴關係與可加入的前側地面。人物距離及前後位置不等，不排成均勻半圓，也不要求全員看訪客或篝火。

## 3. 共同鏡頭與地面

維持 2D 橫向卷軸感，帶少量俯角：可見火圈、木箱上表面、坐姿與接地位置；不改成明顯俯視、等角或寫實透視場景。

角色、道具與地面符合相同觀看角度。前後關係由接地點、清楚遮擋、上表面可見程度與合理相對尺度共同表達，不能只改圖片上下座標。不同坐姿不必把頭排在同一高度，不可任意拉伸人物解決深度。

- 前側：連續、可接近的地面。加入空間須在對話框上方實際可見，不只存在於被 UI 遮住的底部；不新增空椅子、地毯或道具表示訪客位置。
- 中央：篝火、Mimiku、暖手戰士形成緊密但不擁擠的核心，保留安全火圈距離。
- 稍後方：法師與地圖箱、遊俠錯落於同一休息區內，不孤立於房間兩端。

中央前景不再像窄平台或懸崖斷面，地面平緩延伸向訪客；側邊岩石保有層次。不新增深坑、橋梁、階梯障礙或地形故事。

## 4. 人物與道具關係

| 元素 | 擺放與姿態 |
| --- | --- |
| 篝火 | 稍靠前的共同休息中心，周圍是連續地面，不另設場景底座 |
| Mimiku | 火旁、略靠訪客的一側；朝向兼顧伙伴與訪客，不脫離群組、不要求正面看鏡頭 |
| 戰士 | 火堆左側近處暖手，身體朝群組內部，盾牌在外側；手與腿不接觸火焰或火圈 |
| 法師＋地圖箱 | 戰士左後方的安靜閱讀角；視線落向地圖，手靠箱沿，法杖靠身旁；不主持會議或指揮 |
| 遊俠 | 右後方放鬆休息，身體或視線稍朝內，不像獨自守望洞口 |
| 木牌 | 休息區前側邊緣，面向訪客且文字清楚，不堵住加入空間、不遮住 Mimiku |

保留角色身份、服裝、膚色、約 2.25 頭身的底層人物比例與以戰士為基準的細緻像素群。「保持身份」不等於新姿態必須像素逐點相同。

保留已選斜角地圖箱的造型、細節與放大大小；目前 review 寬度基準為桌機 113 logical pixels、手機 79 pixels。位置可配合群組及法師手部調整，不靠縮小木箱降低主次。若草案顯示必須修改木箱角度或大小，先提出理由供使用者判斷。

允許清楚且有限的前後重疊，例如箱子前沿與法師下半身。不得遮住臉、閱讀／暖手的主要動作或地圖辨識區，不得讓身體接觸火焰或火圈。避免輪廓剛好碰到而無法辨別前後的相切。所有物件「零重疊」不是構圖合格條件；既有機械檢查的調整須在後續計畫明列，不得刪除測試掩蓋遮擋缺陷。

## 5. 共享光線與細節主次

篝火仍是唯一強光源，沿用目前已選造型，不另畫更大的火或發光底座。它照亮共同地面、戰士的手與 Mimiku 朝火的一側，法師及遊俠受到較弱、方向一致的暖光影響。

沿用暖棕、羊皮紙、紫色、節制黃銅等辨識色。明暗由兩至三階色帶、刻意像素群與破碎高光表達；接地陰影與局部反光符合共同地面與光源。不使用霧狀平滑光暈、獨立角色聚光燈、過曝金邊或均勻橙色濾鏡。

細節集中於休息區。地圖保留近景細節但不成為第二個大亮點；石壁、通道、普通寶箱、壓力板、壁面刻痕與蝙蝠保留身份及探索用途，以較低對比退到次要層。兩支火把只提供局部較弱照明；背景暗處仍安全、溫暖，不以大塊純黑或深藍營造恐怖。

不為平衡左右重量新增桶、瓶、箱、旗幟、金幣堆或裝飾符號；用群組、留白與對比調整，而非補滿空隙。

## 6. 字標、live UI 與手機

保留使用者選定的 B 石壁結合方式、較小字體及較寬字距、第三／C 亮度方向，供後續分層整合；不重新選字標風格或把生成的整張標題概念圖當作 scene master。目前 v08 live 字標不是完成 v11 整合的證據。

粗略構圖比較使用相同字標與 live UI 處理，避免字標亮度差異干擾擺放判斷。後續字標整合另留視覺 checkpoint，不與構圖選擇混為一次核准。

木牌文字、對話、主要 CTA、登入入口和日誌保持 live、可讀、可操作，不為降低視覺重量犧牲操作入口辨識。對話框不得遮住臉、主要動作、火堆、Mimiku、木牌或全部前側留白。

手機使用同一群組關係，不直接裁切桌機圖。可壓縮左右間隔、增加前後錯落，但保留完整小隊、地圖、木牌及可見加入空間，不改頭身或顆粒尺寸塞入角色。外圍發現延續原規格的初始畫面外探索位置。

後續檢查沿用 320、390、768、1440 viewport，審核實際 live UI 覆蓋，不只看無文字合成圖。

## 7. 下一個 review checkpoint

本文核對通過後，先寫 review-only 實作計畫，再製作兩個粗略構圖草案。兩者皆符合開口式群組、共同鏡頭、連續地面與共享暖光，比較群組緊密程度、前後錯落與前側留白，不比較新畫風、角色造型或房間主題。

草案用於判斷整體佈局，不宣稱角色細節完成。創意 raster 來源以 ImageGen 製作或修訂，參照既有角色；必要的鏡頭／姿態適配另存版本。精修、deterministic 分層輸出及 contract 實作依選定草案與後續計畫安排。

草案審核須確認：

1. 縮小觀看時，第一眼是暖火與伙伴，不是字標、洞口或單張角色。
2. 灰階能區分休息區與背景，角色不是各自獨立照亮。
3. 地面、腳／坐姿、木箱及火圈符合共同鏡頭；沒有漂浮或懸崖窄平台感，合理遮擋能說明前後。
4. 小隊是同一群組且動作自在，法師看圖、戰士暖手可讀，遊俠不脫離群組。
5. 加入空間在實際對話框上方可見，不新增訪客化身或空椅子。
6. 桌機／手機含 live UI 的畫面均成立；尺寸、hash、alpha、無溢位檢查不能取代使用者視覺判斷。

方向核准、核對本文、選擇草案、核准精修稿是不同 checkpoint。每個視覺 checkpoint 都停止等待使用者判斷；任何一項都不自動核准 Scenes family。

## 9. 研究依據

以下來源提供判斷工具；具體擺放是針對 Mimic 的設計推論，不宣稱來源推薦了此佈局。

- [Getty — 平衡、焦點與觀看路徑](https://www.getty.edu/education/teachers/building_lessons/formal_analysis2.html)：共同判斷物件、顏色、質感及空間的視覺重量。
- [NN/G — 視覺層級、平衡與群組](https://www.nngroup.com/articles/principles-visual-design/)：安排觀看順序與群組關係，不用左右件數判定平衡。
- [Animation Mentor — Staging](https://www.animationmentor.com/blog/staging-the-12-basic-principles-of-animation/)：人物視線、場景線條與光線共同引導注意。
- [James Gurney — Tangencies](https://gurneyjourney.blogspot.com/2009/05/tangencies.html)：辨別含糊輪廓接觸與清楚前後關係。
- [Sea of Stars 官方截圖集](https://sabotagestudio.com/presskits/sea-of-stars/)：借鑑營火、連續地面與包覆空間的關係，不照搬角色、鏡頭或場景。
- [Eastward 官方媒體頁](https://eastwardgame.com/media/)：借鑑人物活動群組及外圍物件組織，不照搬俯視角度、畫風或密度。
