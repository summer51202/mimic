- 亮度及 HSV 飽和度以接縫左右各 4 px 的平均除以 x = seam ±16 兩參考欄的平均。3R3 六組均達亮度 92% 和飽和度 85% 門檻。3R2 負向對照有五組飽和度低於門檻，涵蓋兩條接縫。
- 冷色沿用 HSV 色相 90°–330° 且飽和度至少 0.12。兩處 24 px 修正帶各高度帶的冷色比例均低於同高全條平均。
- 色度以 BT.709 YCbCr 計算，沿用 3R2 的亮度量測基準。採前後各 24 列的視窗（右端不含），將色度向 seam−14 與 seam+13 欄的線性插值靠攏，並按規格線性羽化。色域限制沿固定 Y 的方向縮放修正量。浮點 Y 保持一致，8 位元 PNG 取整後最大逐像素亮度差為 0.482／255。
- 相對 3R2 共 24,205 像素變更，其中 12,298 個在中段。變動限於 x 378–401、768–791。帶外 RGBA 與全圖 alpha 逐像素一致。
- 合成前驗證來源背景、擺位回執與圖層的 SHA-256、PNG 尺寸及圖層界線。沿用回執圖層順序與座標。Node 語法檢查通過，重建後背景、八格、layout、HTML 與 manifest 共 12 個 SHA-256 一致。
- Playwright 驅動 Chrome 通過 1440×900、768×1024、390×844、320×640。檢查初始中段、三段按鈕、八格解碼及全寬連結、三張背景、六張 6× 接縫圖的尺寸和捲動範圍、頁面水平溢出與 JavaScript 錯誤。
- 牆面接縫仍較參考欄亮約 11–13%，延續 3R2 的亮度輪廓。接縫在手機實際顯示比例的連續性待目視審核。
