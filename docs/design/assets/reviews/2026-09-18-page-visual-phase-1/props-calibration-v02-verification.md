## 壁畫量測

在預設落點取同一組刻痕中心像素，比較未疊圖的岩壁與疊圖後的亮度。使用 BT.709 RGB 權重，以岩壁平均值為分母。暖色邊緣另行著色，未納入刻痕中心的量測。

| 場景 | 落點及畫布 | 量測像素 | Hidden（6–12%） | Revealed（≥20%） |
| --- | --- | ---: | ---: | ---: |
| 桌機 | (205, 190)，72×48 | 756 | 9.91% | 37.99% |
| 手機探索條 | (945, 163)，54×36 | 390 | 9.99% | 37.97% |

同一畫布與透明輪廓。兩種狀態使用同一 ImageGen 遮罩，刻痕亮度乘數為 0.90 與 0.62。下緣 RGB 增量分別為 [3, 2, 1] 與 [24, 15, 7]。手機依橫向位置作約 1 px 的縱向偏移以貼合斜岩壁。拖動時沿用預設落點色彩，移位後需目視確認對比。

## 檢查結果

- Focused Vitest 通過，2 個檔案、7 項測試。檢查插圖 256×256、透明區沒有隱藏 RGB、刻痕的輪廓與亮度，以及既有擺位模型。Windows 暫存權限下以工作區暫存目錄及 Node 環境重跑。
- Focused ESLint 和 Web typecheck 通過。
- Playwright Chromium 通過，四個 viewport 共 8 項。檢查 320×568、390×844、768×1024、1440×900 的素材載入、兩個場景切換、頁面寬度，以及桌機與手機的壁畫座標、狀態、重設和 JSON 匯出。系統 Edge 啟動失敗後，使用本機 Playwright Chromium 重跑。
- 重新執行 composer，11 個輸出（8 張 PNG、2 個 HTML、1 份專項 manifest）SHA-256 全數一致。
- 共用 review-manifest.json 執行前後 SHA-256 一致，為 8d4ea9b8dcd8aeb8591ae50a951c848097f4a08bd6937e4a7de24d474cf82f4e。
- 已檢視桌機實景的 Revealed 截圖。Hidden 的可發現性、手機貼牆感、四張插圖的家族一致性，以及最終擺位由視覺審核確認。
