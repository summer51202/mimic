# PairFund Design Polish Notes

Date: 2026-04-07
Scope: Mobile and Web mockup polish
Direction: Brand-first polish

## Purpose

Refine the current mockups from structural previews into more presentation-ready product visuals while keeping them implementation-adjacent.

## Brand Principles

### 1. Warm Shared-Life Tone

PairFund should feel like a shared everyday companion, not a cold finance dashboard.

Design expression:

* warm neutrals as the main surface language
* coral accents for primary action and emotional focus
* muted olive and sand tones for supportive states

### 2. Soft Material System

Cards should feel layered and tactile rather than flat.

Design expression:

* rounded corners across all panels
* soft shadow depth
* subtle warm gradients on hero panels
* pale inner surfaces against a slightly darker app background

### 3. Calm Information Hierarchy

Important numbers should stand out, but the overall page should still feel gentle and breathable.

Design expression:

* large, confident balance figures
* smaller warm-gray support text
* grouped sections with clear spacing
* fewer hard dividers, more block separation

### 4. Consistent Action Language

Primary actions should be visually unmistakable.

Design expression:

* filled coral buttons for main CTA
* soft tinted pills for secondary actions
* consistent badge treatment for states like locked, pending, and settled

## Polish Moves Applied

* add soft shadows and depth to major cards
* refine hero panels with more deliberate gradients
* improve CTA contrast and sizing
* use badges and chips to make record state more legible
* align desktop and mobile card rhythm
* reduce placeholder-like flatness in side rails and summary panels

## What This Pass Does Not Try To Do

* create final production design tokens for code
* resolve every long-copy edge case
* add charts, illustrations, or heavy visual decoration
* turn the mockups into marketing shots
